# Windows PC + 스마트폰 실제 확인 순서

이 절차는 본인이 직접 수행한다. 자동 검증 통과는 실제 기기 확인을 대체하지 않는다. 로컬과 배포 도메인의 패스키는 별개이므로 실제 과제용 등록은 배포된 HTTPS 주소에서 진행한다.

## 먼저 준비

- PC: 최신 Chrome 또는 Edge, Windows Hello 설정과 기기 사용자 확인 가능 여부.
- 스마트폰: 패스키 지원 OS와 브라우저, 저장할 패스키 관리자. PC에서 스마트폰을 이용할 때는 두 기기가 가까이 있고 QR 연결에 필요한 Bluetooth를 사용할 수 있어야 할 수 있다.
- 실명·이메일·연락처를 입력하지 않고 별명만 쓴다. 세션·쿠키·기기 PIN·계정 로그인 화면을 캡처하거나 제출하지 않는다.

## 1. PC 패스키를 등록

공개 소개의 ‘패스키로 열기’ → ‘처음이에요 · 메모함 만들기’로 간다. 별명 ‘솜사탕’, 패스키 이름 ‘Windows PC’, 저장할 곳 ‘기기 자체’를 선택한다. 실제 패스키 창에서도 이 PC/Windows Hello를 선택해 등록한다. 메모 3개와 패스키 목록의 이름·날짜를 확인한다. PC 패스키가 실제로 다른 클라우드 관리자에 저장됐다면 기록을 그 제공자에 맞춘다.

## 2. 스마트폰에 별도 패스키를 추가

로그인된 메모함의 ‘예비 패스키 추가’에서 이름을 ‘내 스마트폰’, 저장할 곳을 실제 사용할 관리자에 맞춰 선택한다. 패스키 창에서 ‘다른 기기’/‘휴대전화’ 등을 선택하고 QR을 스마트폰으로 스캔해 등록한다. 선택지가 없으면 스마트폰에서 같은 HTTPS 메모함을 열고 기존 PC 패스키로 로그인할 수 있는지 확인한 뒤 추가 등록한다. 사용자 확인이나 제공자 로그인은 직접 처리한다.

목록에 **서로 다른 credential ID 두 개**가 있어야 한다. 같은 동기화 키가 PC와 휴대전화에 보이는 것만으로는 두 개 등록이 아니다. 같은 제공자가 중복 등록을 제한하면 다른 저장 위치를 사용해야 한다. 도구가 지원하지 않는 실제 기기 조합은 억지로 통과 처리하지 않는다.

## 3. 남은 키와 삭제한 키를 확인

두 키로 각각 로그인되는지 확인한 뒤, 현재 로그인된 상태에서 PC 키를 삭제한다. 자동 로그아웃을 확인하고 스마트폰 키로 다시 들어가 메모가 유지되는지 확인한다. 삭제된 PC 키로 로그인 요청을 보내면 서버가 401로 거절해야 한다. 브라우저가 삭제된 키를 선택지에서 숨겨 시도할 수 없다면 그것만으로 서버 거절 증거를 만들었다고 쓰지 않는다. 기기에 남아 있는 삭제된 키를 실제 선택하거나, 인증 응답을 적절히 확보해 검증한다.

원하는 경우 확인 후 PC 키를 새로 등록해 두 개를 다시 유지한다. 서버에서 삭제하는 것은 이 사이트의 등록 기록이며 기기의 패스키 관리자에 남은 키까지 지우는 작업은 아니다.

## 4. 별도 연습 계정으로 교차 접근 확인

로그아웃한 별도 브라우저 프로필에서 ‘연습B’ 계정과 패스키를 만든다. 서로 다른 가상 메모가 있는지 확인한다. A 로그인으로 B 메모 주소를 요청하고, B 로그인으로 A 메모 주소를 요청해 각각 403을 기록한다. 양쪽 자료 건수를 거절 전후 비교한다.

## 남길 증거

로그인된 화면의 ‘확인 기록 내려받기’를 누르면 서버에 저장된 실제 공개키와 현재 브라우저에서 진행한 등록·로그인 요청·응답을 JSON으로 받을 수 있다. 쿠키·세션 값은 수집하지 않는다. 첫 등록 뒤, 두 키 등록 뒤, 삭제와 재로그인 뒤 각각 받아 둔다. 새로고침하면 요청 기록이 초기화되므로 먼저 내려받는다. 별도 브라우저의 기록은 각각 저장한다. 키 목록 화면과 실제 저장 위치 확인은 별도로 남긴다.

등록·로그인의 서로 다른 challenge 값, 등록 요청 본문(개인키 미포함), 서버 저장 공개키 값, 성공·거절 요청과 응답, 패스키 두 개의 이름·날짜 목록, 등록 취소 안내, 실제 저장 위치. 쿠키·세션·토큰은 가리고 실제 기기 PIN이나 스마트폰 계정 정보는 넣지 않는다.

실제 키 저장 위치와 화면을 확보한 뒤 설명서의 ‘실제 기기 확인 전’ 상태를 바꾼다. 실제 개인정보·비밀값 없는 최종 자료와 공개 결과물·소스 URL을 준비한 뒤 과제 제출을 별도로 진행한다.
