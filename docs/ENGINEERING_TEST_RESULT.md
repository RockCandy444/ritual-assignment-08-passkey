# T08 자동 검증

검증 시각: 2026-10-06T05:56:23.859Z

실제 HTTP와 로컬 D1을 대상으로 60개 확인을 통과했다. WebAuthn 형식의 합성 인증기가 실제 ECDSA 키와 서명을 만들어 검증했다. 이는 실제 기기 등록이나 사용자 생체 인증을 대신하지 않는다. 개인키는 실행 중 메모리에만 존재하고 기록·파일에 저장하지 않았다.

확인: 공개 소개 보존, 미로그인 401, HTML에 메모 미포함, 계정 간 양방향 403, URL·본문 계정 ID 변조 시 본인 자료만 반환, 자료 건수 보존, 등록 취소, CSRF, 서명 변조, origin·userHandle 변조, challenge 재사용·동시 재사용, 로그아웃 세션 재사용, 서로 다른 패스키 두 개, 마지막 키 삭제 방지, 삭제 후 세션 무효화, 삭제한 키 실패와 남은 키 성공.

요청·응답은 ENGINEERING_EVIDENCE.json에 있다. 쿠키는 가렸다. 아직 필요한 확인: 공개 운영 환경의 실제 패스키 등록·저장 위치, 기기 로그인, 실제 두 키 관리, 새 시크릿 창 공개 접근.
